
# Práticas de CSS

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web, do curso de Análise e Desenvolvimento de Sistemas.

A atividade tem como objetivo aplicar conceitos de estilização CSS, seletores, pseudoclasses, Flexbox, Grid e responsividade.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades e conceitos aplicados

- Estilização de textos, cores e espaçamentos
- Seletores e pseudoclasses como `:hover`, `:focus-visible` e `:nth-child()`
- Organização de cartões utilizando Flexbox
- Estruturação da página com CSS Grid e `grid-template-areas`
- Layout responsivo com Media Queries
- Navegação interna entre seções

## Estrutura do projeto

```text
praticas-css/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Como executar

1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## Sobre a atividade

A atividade foi dividida em três partes práticas:

- **Parte A:** estilização básica, listas e pseudoclasses.
- **Parte B:** criação de cartões utilizando Flexbox.
- **Parte C:** construção de um layout com CSS Grid e responsividade.

As três partes foram integradas em uma única página web.
